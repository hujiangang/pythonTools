# 完整处理 (去水印 + 语音识别 + 字幕)
python watermark_remover_asr.py input.mp4 -o ./output

# 仅去水印
python watermark_remover_asr.py input.mp4 -o ./output --no-subtitle

# 仅语音识别 + 字幕
python watermark_remover_asr.py input.mp4 -o ./output --no-watermark

# 仅提取音频和内嵌字幕
python extract_media.py input.mp4 -o ./output/extracted

# 双击/一键提取音频和内嵌字幕
run_extract_media.bat

# 点击选择水印坐标
python pick_region.py input.mp4 --time 1 --start 0 --end 4 --name 右下

# 双击/交互式选择水印坐标
run_pick_region.bat

# 也可以直接传参数：截图秒数 开始秒数 结束秒数 名称
run_pick_region.bat 1 0 3 右下
run_pick_region.bat 5 3 6 左中
run_pick_region.bat 8 6 10 右上

说明:
打开窗口后，用鼠标拖拽水印区域，或依次点击水印左上角和右下角。
按 Enter 或空格输出可直接复制到 watermark_regions 的配置。
按 R 重选，按 S 保存带框预览图，按 Q 或 Esc 退出。
如果 OpenCV 窗口不可用，脚本会自动生成 input_pick_region.html。
用浏览器打开该 HTML 后拖拽水印区域，文本框里会显示可复制的配置。
